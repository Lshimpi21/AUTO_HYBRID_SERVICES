## 🚀 Quick Start

### Prerequisites
```bash
Node.js 16+
npm 8+
Git
```

### Development Setup

1. **Clone Repository**
```bash
git clone https://github.com/yourusername/AUTO_HYBRID_SERVICES.git
cd AUTO_HYBRID_SERVICES
```

2. **Install Dependencies**
```bash
npm run install:all
```

3. **Create Environment File**
```bash
cp .env.example .env.local
```

4. **Configure Environment Variables**
```env
REACT_APP_API_URL=http://localhost:5000/api
REACT_APP_WHATSAPP_NUMBER=919834446217
```

5. **Run Development Server**
```bash
npm run dev
```

6. **Access Application**
```
Frontend: http://localhost:3000
Backend: http://localhost:5000
```

## 📤 Deployment to Vercel

### Step 1: Connect GitHub
1. Push code to GitHub
2. Go to vercel.com
3. Select "Import Project"
4. Choose your GitHub repository

### Step 2: Configure Build
```
Build Command: cd client && npm run build
Output Directory: client/build
```

### Step 3: Add Environment Variables
```
REACT_APP_API_URL=https://auto-hybrid-services-shop.app/api
REACT_APP_WHATSAPP_NUMBER=919834446217
```

### Step 4: Deploy Custom Domain
1. Purchase domain from GoDaddy/Namecheap
2. Add to Vercel dashboard
3. Update nameservers
4. Wait for DNS propagation (24-48 hours)
